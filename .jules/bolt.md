## 2026-02-20 - Fix N+1 Query in CampaignViewSet.list
**Learning:** The `list` method of `CampaignViewSet` loops through serialized campaign data and performs a database query (`mediosxcampania.objects.filter(campania_id=x['id'])`) for each iteration. This is a classic N+1 query problem, leading to poor performance as the number of campaigns increases. Also `contactosxcampSerializer` accesses `medio_id.tipo_medio`, which without `select_related`, causes another set of N+1 queries.
**Action:** Extract all IDs from `serializer.data`, fetch all related `mediosxcampania` in a single query using `__in=ids` and `select_related('medio_id__tipo_medio')`, group them by `campania_id_id` in memory using `collections.defaultdict`, and assign them to the serialized data. Note that `campania_id_id` must be used because the field is named `campania_id` on the model.
