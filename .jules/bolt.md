## 2025-02-20 - [Fix N+1 in CampaignViewSet.list]
**Learning:** Found an N+1 query problem in `CampaignViewSet.list` where `mediosxcampania.objects.filter(...)` was called in a loop for each serialized campaign. The serialized campaign ID was used to lookup the models. Because `contactosxcampSerializer` uses `source='medio_id.tipo_medio'`, each loop also resulted in an extra query to `Medio` and `Tipo_medio`.
**Action:** Bulk fetching the `mediosxcampania` models for the paginated result mapping the models to the campaign and explicitly loading the related foreign keys via `select_related('medio_id', 'medio_id__tipo_medio')` resolves both sets of queries reducing query count from ~26 on a 5 element list down to exactly 2. Always map IDs and fetch en masse with `select_related` in `list` actions!
