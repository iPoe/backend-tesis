## 2024-05-28 - N+1 Query Fix in CampaignViewSet.list
**Learning:** Found a severe N+1 query performance bottleneck in `CampaignViewSet.list`. The code was iterating through serialized campaigns and querying `mediosxcampania` for each one, causing 3 queries per campaign (601 queries for 200 campaigns). Additionally, during serialization of `mediosxcampania` in `contactosxcampSerializer`, it was hitting `medio_id.tipo_medio`, which without `select_related` caused more queries.
**Action:** Bulk fetched `mediosxcampania` using `.filter(campania_id__in=ids)` with `.select_related('medio_id__tipo_medio')`, constructed an in-memory `defaultdict` for O(1) lookups, dropping queries from 601 to just 2 and drastically reducing execution time (from ~0.37s to ~0.06s for 200 campaigns).
