## 2024-07-18 - Fast bulk insert upserts in Django REST Framework
**Learning:** When using DRF serializers to bulk create objects (e.g. `ContactosSerializer(data=data, many=True)`), DRF natively falls back to looping over `validated_data` and calling `.create()` sequentially. When each `.create()` performs an `update_or_create` on the model, it causes extreme N+1 query problems (e.g., 600 queries for 100 rows). We can resolve this using PostgreSQL's native `bulk_create(update_conflicts=True)` directly in the custom list serializer to act as an upsert, which reduces query count to ~3 and shrinks execution time drastically.
**Action:** For serializers frequently handling large payload lists, explicitly define a `ListSerializer` class and assign it via `list_serializer_class = MyListSerializer` in the `Meta` class. In the `MyListSerializer.create()` override, convert all `validated_data` dicts to Model instances, then use `bulk_create` passing `update_conflicts=True`, `unique_fields`, and `update_fields` to bypass N+1 loops and get bulk performance.
