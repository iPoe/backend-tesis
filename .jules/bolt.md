## 2025-07-21 - N+1 query vulnerability in Python list comprehensions
**Learning:** List comprehensions in Django (e.g., `[c.campania for c in campañas_usuaria if c.campania.estado == estado_activo]`) cause immediate evaluation of lazily loaded foreign key properties (`c.campania` and `c.campania.estado`). When these fields are unoptimized, it triggers multiple queries per item (N+1 bottleneck) because the ORM traverses the relationship individually for each item in the comprehension.
**Action:** Always proactively append `.select_related()` (for `ForeignKey` or `OneToOneField`) or `.prefetch_related()` (for `ManyToManyField` or reverse relations) on the base QuerySet when fields will be traversed recursively or conditionally during Python-side iteration or list comprehension.
