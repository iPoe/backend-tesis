## 2024-07-05 - Django REST Framework Bulk Insert with PostgreSQL Upsert Optimization
**Learning:** By default, initializing a Django REST Framework ModelSerializer with `many=True` and calling `.save()` delegates saving to the child serializer iteratively, executing an N+1 query pattern where each item generates a distinct `INSERT` (or `SELECT`+`UPDATE` / `INSERT`). In environments using PostgreSQL (or versions of SQLite with conflict handling), this can be overridden effectively in DRF by declaring a custom `ListSerializer`.
**Action:** Always intercept bulk insertions in DRF by setting `list_serializer_class` on the `ModelSerializer.Meta`. Override the custom `ListSerializer`'s `create()` method to unpack validated data into model instances, and use `Model.objects.bulk_create(instances, update_conflicts=True, unique_fields=[...], update_fields=[...])` to ensure robust upsert operations that condense O(N) database operations down to O(1) bulk commands.
