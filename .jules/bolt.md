## 2025-02-23 - Bulk Updates Using Django Q Objects
**Learning:** In Django, when iterating over pairs of unrelated foreign keys (like `campania_id` and `medio_id`) to perform updates, executing queries inside a for-loop leads to severe N+1 bottlenecks. However, Django does not natively support `update()` operations with a list of tuples. Passing an empty `Q()` object to `filter()` and calling `update()` will cause unintended mass updates across all records matching other conditions.
**Action:** Use `Q` objects chained with the `|=` operator to dynamically construct the complex query for multiple disparate criteria pairs. **Critically**, always check if the list generating the `Q` objects is empty and return early *before* executing the `update()`, to prevent catastrophic data modifications affecting the entire table.
