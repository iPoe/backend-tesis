## 2024-05-24 - N+1 Query in Django Rest Framework ListSerializer with Nested Logic
**Learning:** In DRF viewsets, performing an ORM `filter()` inside a loop over `serializer.data` creates a catastrophic N+1 query problem, especially if the subsequent child serializer (`contactosxcampSerializer`) also relies on deeply nested relations (`source='medio_id.tipo_medio'`) which trigger further database round-trips for every item.
**Action:** When a serializer method or a `list` action loops over objects to attach child data, always pre-fetch the related objects in bulk before the loop using `.filter(id__in=ids).select_related(...)`. Then construct a memory dictionary (like `defaultdict(list)`) to group the child objects by the parent ID for O(1) in-memory lookups, completely eliminating the N+1 database calls.
