## 2025-02-28 - Fixing N+1 Query in CampaignViewSet.list
**Learning:** The `CampaignViewSet.list` method fetches all campaigns, but then loops over the serialized campaigns and performs a separate `mediosxcampania.objects.filter(campania_id=x['id'])` query for each campaign. Additionally, the nested `contactosxcampSerializer` accesses `medio_id.tipo_medio`, creating an extra query per `mediosxcampania` instance due to a lack of `select_related`. This was causing 51 queries for 10 campaigns. Django N+1 query problems within loops over serialized data can be mitigated using `.filter(id__in=ids)` mapped via a dictionary, and by chaining `.select_related()` for fields accessed within nested serializers (e.g. `source='medio_id.tipo_medio'`).
**Action:** Always check loop structures iterating over serializers to spot N+1 queries. When found, prefetch related instances before the loop using `__in` and group them into a `defaultdict` for O(1) lookup during assignment.
