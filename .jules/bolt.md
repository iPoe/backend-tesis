## 2024-05-15 - [Bolt: N+1 Optimization in ViewSet Iteration]
**Learning:** Found an N+1 query problem during the manual dict building in `CampaignViewSet.statistics`. In this specific application, because they're looping over aggregated DB values (`resultados`), `Contacto` instances were retrieved individually using `Contacto.objects.get` on every loop iteration where the `contacto_cc` changes, resulting in many sequential calls.
**Action:** Replace `objects.get()` loops inside list iteration by aggregating the necessary keys from the raw values dict (in this case `contacto_cc` from `resultados`), and then use Django's `Model.objects.in_bulk(ids, field_name='pk')` prior to the loop. This converts O(N) database queries into a single query mapped for O(1) dictionary lookups.
