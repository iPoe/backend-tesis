## 2024-07-29 - Optimize N+1 queries in Celery Tasks using select_related
**Learning:** When Django celery tasks perform batched inserts using an `objects.bulk_create` call alongside related model instance properties (e.g. `obj.contacto.celular`), the evaluation of the related instances can cause severe N+1 query bottlenecks on the task workers. These backend loops are often missed when focusing purely on viewsets/serializers, but they represent a significant performance penalty for background tasks.
**Action:** When inspecting backend systems for performance opportunities, remember to scrutinize background task loops that perform manual object orchestration or iterate across querysets. Utilize `.select_related()` to pre-fetch required relationship values and pass the in-memory variables directly into any `bulk_create` objects.
