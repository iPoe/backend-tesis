## 2024-05-16 - Prevent N+1 queries when returning related models in Django Rest Framework list views
**Learning:** Returning related models via nested serializers inside a loop over `serializer.data` triggers severe N+1 database queries. A custom `.list` method in `CampaignViewSet` executed an extra query for `mediosxcampania` per campaign. Furthermore, explicitly fetching the `Foreignkey` model in the loop can cause additional N+1 queries if lazy evaluation isn't addressed.
**Action:** Bulk fetch the related instances using `.filter(id__in=ids)` prior to the loop. Use `select_related()` (or `prefetch_related()`) to join fields needed for serialization. Crucially, group the results in an in-memory dictionary grouped by the foreign key's database ID field (e.g. `campania_id_id`) for O(1) retrieval during the loop, eliminating database hits entirely.
