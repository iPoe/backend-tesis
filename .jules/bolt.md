## 2024-08-12 - N+1 Query in CampaignViewSet.list
**Learning:** The `list` method in `CampaignViewSet` has an N+1 query problem because it iterates over the serialized data of `Campania` and runs a `.filter()` query on `mediosxcampania` for each record. And further `contactosxcampSerializer` is serializing it which does `medio_id.tipo_medio` which triggers queries for `medio_id` and `tipo_medio`. Wait, the query count was 31 for 10 records: 1 query for `Campania.objects.all()`, and then for each of the 10 campaigns, it queries `mediosxcampania` (10 queries), and then for each `mediosxcampania` it fetches the `medio` and `tipo_medio` (20 queries).
**Action:** Use `defaultdict` to bulk fetch all `mediosxcampania` items in a single query and map them by `campania_id_id`, while using `select_related('medio_id', 'medio_id__tipo_medio')` to avoid N+1 queries when accessing nested relations.
