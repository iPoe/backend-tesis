## 2024-06-03 - N+1 Queries in DRF ModelViewSet List Methods
**Learning:** In Django Rest Framework `ModelViewSet`s, overriding the `.list()` method to append nested relational data by querying inside a loop over `serializer.data` causes severe N+1 query bottlenecks. Standard `prefetch_related` is often bypassed when the data structure mapping doesn't perfectly match standard ORM relationships or requires custom logic per-item post-serialization.
**Action:** When populating nested related lists across a DRF dataset, use a single `.filter(foreign_key__in=[item['id'] for item in data])` query with `.select_related()` to fetch everything at once. Use Python's `collections.defaultdict(list)` to group the fetched records by their foreign key (e.g., `item.foreign_key_id`) in memory, achieving O(1) lookups during the list construction loop and reducing total queries from 1+N to 2.
