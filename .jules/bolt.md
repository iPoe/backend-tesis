## 2024-07-12 - Optimizing DRF child iteration update_or_create with native bulk_create
**Learning:** In Django Rest Framework, a serializer that iterates over its child items to call `update_or_create` triggers significant N+1 queries. We can eliminate this performance bottleneck by overriding the `ListSerializer.create` method and replacing iterative `update_or_create` with PostgreSQL's native `bulk_create` configured to `update_conflicts=True`. This reduces database hits significantly (e.g., from 6N queries down to 1 query).
**Action:** When working on applications with bulk imports or mass data loading, check for the N+1 trap in list serializers and apply `bulk_create(update_conflicts=True)` whenever the backend provides native upsert functionality like PostgreSQL does. Ensure the unique constraint allows handling it cleanly.
