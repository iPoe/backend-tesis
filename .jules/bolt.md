## 2024-10-24 - Identifying bottleneck in `CampaignViewSet.statistics` N+1 query problem
**Learning:** `CampaignViewSet.statistics` has an N+1 query bottleneck because it iterates through the `resultados` (results grouped by user) and inside the loop it fetches each `Contacto` individually with `Contacto.objects.get(identidad=contacantiguo)` and passes it to `ContactosSerializer`.
**Action:** Replace the individual `Contacto.objects.get` lookups with a bulk lookup using `Contacto.objects.in_bulk()` based on the unique list of `contacto_cc` collected from the results.
